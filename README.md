# Legal Document Text Summarizer

A modern Django web application to summarize lengthy legal documents quickly and effectively using AI -powered natural language processing. Designed with a clean, Indian-themed UI for ease of use by legal professionals, students, and researchers.

---

## Features

- Paste large legal texts and get concise summaries.
- Sentiment analysis of the summarized text.
- Clean, aesthetic Indian-themed frontend with modern fonts.
- Built with Django and Python libraries like TextBlob, Newspaper3k, and BeautifulSoup.
- Secure and extensible codebase, ready for further enhancement.
